1. Чем ветка отличается от копии папки с проектом?
ветка это указатель, который ссылается на определённый коммит.
копия папки с проектом, это копия проекта которая весит столько же и занимает место на диске.


2. Что произойдёт с историей, если удалить папку проекта, но сохранить `.git`?
С историей ничего не произойдёт. Ничего не пропадёт, кроме не сохранённых изменений.


3. Зачем нужен Pull Request, если можно коммитить сразу в `main`?
Если над проектом работает один человек, то можно коммитить сразу в main, но если над проектом работает группа разработчиков, то желательно использовать Pull-Request.
Pull-Request - это запрос на включение изменений в main, по мимо этого в PR можно провести Code Rewiew, автоматические тесты и устроить дискуссию на тему PR
